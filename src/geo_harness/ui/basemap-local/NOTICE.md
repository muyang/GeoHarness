# Offline basemap assets for local review

These geographic assets were extracted from the user's supplied Mogan offline snapshot, solely to reproduce its low-zoom map/globe during local review. They are not API fixtures or scientific input to the NDVI computation.

The reference displays attribution to **OpenFreeMap**, **OpenMapTiles**, and **OpenStreetMap**. Keep that attribution in the UI. The inventory records the exact extracted asset paths, sizes and SHA-256 hashes. Vector tiles are supplied only through zoom 1; raster tiles through zoom 2. Glyph coverage is limited.

The original snapshot does not supply a complete per-asset license manifest. Public redistribution of this extracted set is therefore **not verified**; resolve upstream provenance/licensing or replace it with configured, properly attributed upstream basemap services before publishing. This does not prevent the requested local comparison/demo.
